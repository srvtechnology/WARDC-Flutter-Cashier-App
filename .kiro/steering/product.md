# Product Overview

Western Area Rural District Council (WARDC) mobile application for property assessment and tax collection in Sierra Leone.

## Purpose

Field application for council officers to:
- Register and assess properties for taxation
- Collect property tax payments
- Manage landlord and tenant information
- Track property locations with GPS coordinates
- Handle offline data synchronization

## User Roles

- **Assessment Officers**: Register properties, conduct assessments, manage property data
- **Cashiers**: Process payments, search payment records

## Key Features

- Multi-step property registration wizard (landlord, property, occupancy, geo-registry, assessment)
- Offline-first architecture with local caching
- GPS location tracking and digital addressing
- Image capture for property documentation
- Dual authentication system (separate logins for officers and cashiers)
- Property search and payment tracking
